## Cómo ejecutar el proyecto

El proyecto usa rutas relativas y ES modules; se recomienda un servidor local:

```bash
git clone https://github.com/Alexander777444/Portafolio-Alexander.git
cd Portafolio-Alexander
npx serve .
```

Abre en el navegador la ruta `/Pages/index.html` (por ejemplo `http://localhost:3000/Pages/index.html`).

Alternativas: extensión **Live Server** en VS Code, o `python -m http.server` desde la raíz del repo.
